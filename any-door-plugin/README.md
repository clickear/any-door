# AnyDoorPlugin 任意门插件

## 插件原理
Java attach：通过jvm提供的功能，直接通过进程号进行跨进程调度

## IDEA 兼容范围
- IntelliJ IDEA 2024.3 及以上版本
- 兼容矩阵：2024.3、2025.1、2025.2、2025.3、2026.1、2026.2

## 返回结果查看器（2.8.0）

从方法调用面板或 `.anydoor` 请求执行调用后，打开 **Any-Door → Results** 查看结果。

- 左侧保留当前项目会话最近 100 条调用，显示运行中、成功或异常状态，以及目标和耗时。
- **Tree** 以 JSON 树展示对象、数组和字段；**Raw** 展示完整 JSON 或异常堆栈。
- 搜索框可定位字段名、路径或值；选中节点后使用 **Copy Value** 复制值、**Copy Path** 复制 JSONPath，或用 **Copy JSON** 复制完整结果。
- 普通字符串、JSON 对象和 `null` 分别展示；异步调用完成后更新结果，批量结果按输入顺序排列。

Attach 模式等待结果最多 5 分钟；超时仅表示停止等待，不会取消目标方法。历史仅保存在内存中，**Clear** 可清空记录。
升级后请重启已加载旧 Agent 的目标 Java 进程；HTTP 模式需要将应用中的 AnyDoor 依赖同步升级到 2.8.0。
